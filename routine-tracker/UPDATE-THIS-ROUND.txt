ROUTINE TRACKER UPDATE

Replace these files:
- Copy server.txt into your existing server.js.
- Copy app.txt into public/app.js.
- Replace public/index.html and public/styles.css.
- Add public/favicon.svg.

Keep .env, data/, package.json and node_modules. Restart with START-ROUTINE-TRACKER.bat.

Google Tasks: Enable Google Tasks API in Google Cloud Console, then use Settings & Sync > Reconnect / switch account and approve the Tasks permission. This creates Google Tasks rather than Calendar events. Google Tasks due dates are date-only; Google documents that the time portion is discarded.

Activity deletion permanently removes the selected completion record. For interval routines, next due date is recalculated from the latest remaining completion, or set to today if none remains.
